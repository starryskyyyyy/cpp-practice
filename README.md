# 代码练习仓库

华南理工大学 信息工程 大一 的课程与自学代码练习。

## 目录结构

- `cpp/` —— C/C++ 课程与练习代码
- `python/` —— Python 练习代码

## 环境

- 编辑器：VS Code
- C++ 编译器：g++（MinGW）
- 版本管理：Git

## 说明

本仓库用于记录学习过程。每次完成一个练习就提交一次，
提交说明写清楚做了什么，方便日后回顾。

## 本地运行

```bash
# C++
cd cpp
g++ 文件名.cpp -o 文件名
./文件名

# Python
cd python
python 文件名.py
```
